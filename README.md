# ClassroomLink

A Local Network-Based Interactive Classroom
Screen-Sharing and Laboratory Device Streaming System.

## Technology Stack

### Backend
- Python 3.13
- FastAPI
- Uvicorn

### Frontend
- Jinja2
- HTMX
- Tailwind CSS 4
- DaisyUI
- Iconify
- JavaScript

### Real-time Communication
- WebRTC
- FastAPI WebSockets

### Database
- SQLite
- SQLModel
- aiosqlite
- Alembic

## Development Requirements

- Windows 10/11
- Python 3.13
- Node.js and npm
- Git
- PowerShell
